## 1. 通信总体说明

### 1.1 通信对象定义
- **节点（Node）**：工业智能节点模块（传感器 / 执行器）
- **网关 / 上位机（Host）**：PC 程序或 Android App
- **通信方向标识**  
  - `Host → Node`
  - `Node → Host`

---

## 2. 通信分层结构

| 层级 | 说明 |
|---|---|
| 物理层 | 无线透传模块 + 串口 |
| 链路层 | 串口数据格式 |
| 应用层 | 帧结构 + CRC16 |

---

## 3. 串口通信参数（物理层 + 链路层）

| 参数 | 值 |
|---|---|
| 通信方式 | 串口 |
| 波特率 | **115200 bps** |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控制 | 无 |
| 传输方式 | 全双工 |
| 字符格式 | 1 起始位 + 8 数据位 + 1 停止位 |

---

## 4. 应用层帧结构（固定 16 字节）

```
┌────┬──────┬────────┬────┬──────────┬────────┬──────────┐
│HEAD│LENGTH│ ADDR   │CMD │DATA TYPE │  DATA  │ CRC16    │
│1B  │1B    │ 4B     │1B  │1B        │ 6B     │ 2B       │
└────┴──────┴────────┴────┴──────────┴────────┴──────────┘
```

### 4.1 字段说明

| 字段 | 长度 | 说明 |
|---|---|---|
| HEAD | 1B | Host→Node: `0xCC`；Node→Host: `0xBB` |
| LENGTH | 1B | **固定 0x10 (16)** |
| ADDR | 4B | 设备大类 + 子类 + 索引 |
| CMD | 1B | 功能码 |
| DATA TYPE | 1B | 数据类型 |
| DATA | 6B | 数据内容 |
| CRC16 | 2B | CRC 校验 |

---

## 5. 地址域 ADDR（4 字节）

```
Byte1        Byte2        Byte3        Byte4
设备大类     子类型高字节 子类型低字节  设备索引
```

### 5.1 设备索引
- 范围：`0 ~ 254`
- `255 (0xFF)`：广播（预留）

## 10. DATA 数据域（6 字节）——**控制命令**

### 10.1 通用规则
- 未使用字节 **必须填 0**
- 控制值通常在 **DATA[5] 或 DATA[4~5]**

### 10.2 典型控制格式示例

#### 10.2.1 窗帘
| DATA[5] | 含义 |
|---|---|
| 0x00 | 停止 |
| 0x01 | 打开 |
| 0x02 | 关闭 |

#### 10.2.2 调光灯
| DATA[5] | 含义 |
|---|---|
| 0x00 | 关闭 |
| 0x01~0x09 | 亮度等级 |

#### 10.2.3 电磁阀 / 风扇 / 插座
| DATA[5] | 含义 |
|---|---|
| 0 | 关闭 |
| 1 | 打开 |

#### 10.2.4 8 路继电器
- DATA[4~5] 按 bit 控制
- 每 2 bit 表示一路：
  - `00` 断电
  - `01` 通电
  - `10` 不处理

---

## 11. DATA 数据域 —— **定时上传数据（CMD=0x03）**

### 11.1 Bool 类设备
```
DATA[5] = 0 正常
DATA[5] = 1 异常
```

### 11.2 整型 / 浮点型
- 浮点：DATA[1~4] 为数值
- DATA[0]：符号位（0 正 / 1 负）
- 0xFF：传感器损坏/未接

---

## 12. CRC16 校验

| 项目 | 值 |
|---|---|
| 算法 | CRC16 |
| 初值 | 0xFFFF |
| 多项式 | 0xA001 |
| 字节序 | **低字节在前，高字节在后** |
| 计算范围 | 除 CRC 外所有字节 |

---

## 13. 强烈建议的工程实现方式

- 抽象 `Frame` 结构体
- 统一 `encode()` / `decode()`
- 地址、CMD、DATA TYPE 使用枚举
- CRC 单独模块
- 浮点统一缩放处理
