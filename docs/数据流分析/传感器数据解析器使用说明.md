# 传感器数据解析器使用说明

## 概述

本解析器基于《工业节点通信协议V1.1.pdf》协议文档和现有的`simple_receiver.js`代码，实现了对多种传感器数据的解析功能。支持解析以下传感器类型：

1. 空气温度
2. 空气湿度
3. 雨雪
4. 光照强度
5. 人体感应
6. 土壤温度
7. 土壤湿度
8. 二氧化碳
9. PH值
10. 风速
11. 风向
12. 烟雾

## 文件说明

### 主要文件

1. **sensor_parser.js** - 主程序文件
   - 完整的传感器数据解析器
   - 包含TCP客户端连接功能
   - 实时解析和输出传感器数据

2. **test_parser_standalone.js** - 测试脚本
   - 独立的测试程序
   - 包含所有解析函数的测试用例
   - 可用于验证解析逻辑

### 相关文件

1. **simple_receiver.js** - 原始数据接收器
   - 仅接收原始数据，不进行解析
   - 作为参考实现

2. **工业节点通信协议V1.1.pdf** - 协议文档
   - 通信协议规范
   - 数据帧格式定义
   - 传感器类型映射

## 使用方法

### 1. 运行传感器数据解析器

```bash
node sensor_parser.js
```

程序将自动连接到 `yoned.xyz:2012` 服务器，开始接收并解析传感器数据。

### 2. 输出格式

程序提供两种输出格式：

#### JSON格式输出（stdout）
```json
{
  "timestamp": "2025-12-30T10:30:00.000Z",
  "deviceIndex": 0,
  "category": "通信类",
  "deviceName": "空气温度传感器",
  "sensorType": "air_temperature",
  "value": 25.5,
  "unit": "°C",
  "dataType": "浮点型",
  "function": "定时上传设备数据",
  "rawData": "00 00 00 03 e7 00"
}
```

#### 人类可读格式输出（stderr）
```
[2025-12-30T10:30:00.000Z] 空气温度传感器 (设备0): 25.5 °C
```

### 3. 修改服务器配置

如果需要修改连接的服务器地址和端口，编辑`sensor_parser.js`文件中的以下配置：

```javascript
const HOST = 'yoned.xyz';  // 服务器地址
const PORT = 2012;         // 服务器端口
```

### 4. 运行测试

```bash
node test_parser_standalone.js
```

测试脚本将验证所有解析函数的正确性。

## 数据帧格式

根据协议文档，数据帧格式如下：

| 字段 | 长度 | 说明 |
|------|------|------|
| 包头 | 1字节 | 节点→上位机：0xBB |
| 帧长度 | 1字节 | 固定为16 |
| 地址域 | 4字节 | 设备大类型(1) + 子类型(2) + 索引(1) |
| 功能域 | 1字节 | 0x03=定时上传数据 |
| 数据类型 | 1字节 | 0x01=布尔型, 0x02=整型, 0x03=浮点型 |
| 数据域 | 6字节 | 传感器数据 |
| 校验域 | 2字节 | CRC16校验（低字节在前） |

## 支持的传感器类型

### IO类大类型 (0x01)
- 0x0001: 火灾/烟雾传感器
- 0x0003: 人体感应传感器
- 0x0004: 雨雪传感器
- 0x000A: 土壤湿度传感器
- 0x000B: 土壤温度传感器

### 通信类大类型 (0x03)
- 0x0001: 光照强度传感器
- 0x0002: 空气温度传感器
- 0x0003: 空气湿度传感器
- 0x000A: 二氧化碳传感器
- 0x000D: 风速传感器
- 0x000E: 风向传感器
- 0x000F: PH计

## 数据类型解析

### 1. 布尔型 (0x01)
- 数据域字节6：0=正常/关闭，1=异常/打开
- 适用于：人体感应、雨雪、烟雾等开关量传感器

### 2. 整型 (0x02)
- 数据域字节5-6：16位整数值
- 适用于：光照强度、空气湿度、土壤湿度、二氧化碳浓度、风向

### 3. 浮点型 (0x03)
- 数据域字节3-6：32位整数值，需要除以10000
- 字节2：0=正数，1=负数，0xFF=损坏/未接
- 适用于：空气温度、土壤温度、风速、PH值

## 错误处理

1. **CRC校验失败**：程序会输出错误信息并丢弃该帧数据
2. **未知设备类型**：输出原始数据并标记为未知设备
3. **连接错误**：输出错误信息并尝试重新连接
4. **数据损坏**：自动跳过无效数据帧

## 注意事项

1. 浮点型数据在显示时会保留4位小数精度
2. 程序使用缓冲区管理，确保数据完整性
3. 按Ctrl+C可安全退出程序
4. 所有错误信息输出到stderr，不影响JSON格式输出

## 扩展说明

如需添加新的传感器类型支持，需要：

1. 在`DEVICE_SUBTYPE`映射表中添加新的设备类型
2. 在`parseSensorData`函数中添加对应的数据解析逻辑
3. 更新测试用例以验证新功能
